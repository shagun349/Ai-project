A* Pathfinding Algorithm in 3D Space

f(n) = g(n) + h(n)
g(n) — Actual cost from the start to the current cell.
h(n) — Estimated cost to the goal (Manhattan Distance: |Δrow| + |Δcol|).
f(n) — Total estimated cost of the cheapest path through this cell.

A* always expands the cell with the lowest f(n). Using Manhattan distance as an admissible heuristic guarantees the shortest path on a 4-directional grid.
